================================================================================
04 - PROJECT: 4-BIT BINARY CALCULATOR (RIPPLE-CARRY ADDER)
The flagship build. Adds two numbers 0-15, displays 0-30 on LEDs.
================================================================================

WHAT IT DOES
  8 switches = two 4-bit binary numbers, A (0-15) and B (0-15).
  5 LEDs = the sum in binary, 0-30.
  Purely combinational: flip switches, answer appears instantly. No enter key.

WHY IT WORKS
  Sum   = A XOR B XOR Cin
  Carry = (A AND B) OR ((A XOR B) AND Cin)
  No inversion anywhere, so every term maps onto a gate that exists in Islands.

--------------------------------------------------------------------------------
BLOCK COUNT
--------------------------------------------------------------------------------
  Bit 0 is a HALF adder (no carry-in), bits 1-3 are FULL adders.

  Xor Gate .......  7   (1 for bit0, 2 each for bits 1-3)
  And Gate .......  7   (1 for bit0, 2 each for bits 1-3)
  Or Gate ........  3   (carry merge, bits 1-3 only)
  Splitter ....... 14   (2 for bit0, 4 each for bits 1-3)
  Switch .........  8   (input A0-A3, B0-B3)
  LED Light ......  5   (S0-S3 plus final carry = the 16s place)
  ------------------------------
  LOGIC BLOCKS ... 44
  Steam Generator   2   (see power notes - one is not enough)
  ------------------------------
  TOTAL .......... 46 blocks

--------------------------------------------------------------------------------
LAYOUT
--------------------------------------------------------------------------------
Build it as 4 identical rows on flat ground, left to right, one row per bit.
Leave 2 blocks of walking space between rows or you will not be able to reach
the wire ports.

   footprint: roughly 12 blocks wide x 14 blocks deep. Clear the area first.

   ROW 3 (bit 3, MSB)  [SW A3][SW B3] .. 9 blocks .. -> LED S3
   ROW 2 (bit 2)       [SW A2][SW B2] .. 9 blocks .. -> LED S2
   ROW 1 (bit 1)       [SW A1][SW B1] .. 9 blocks .. -> LED S1
   ROW 0 (bit 0, LSB)  [SW A0][SW B0] .. 4 blocks .. -> LED S0

   Carry runs UPWARD between rows: row0 carry -> row1, row1 -> row2,
   row2 -> row3, row3 carry -> LED S4 (the 16s place).

   Put the 5 LEDs in a straight line on a wall so you can read the number
   left-to-right: [S4][S3][S2][S1][S0]. Face them the same direction.

--------------------------------------------------------------------------------
BUILD ORDER
--------------------------------------------------------------------------------
STEP 1 - Bit 0 (half adder). Get this working alone before touching anything else.
  Place: SW A0, SW B0, SPL_A0, SPL_B0, XOR0, AND0, LED S0.
  Wire:  GEN -> SW A0 -> SPL_A0
         GEN -> SW B0 -> SPL_B0
         SPL_A0 out1 -> XOR0 in1     SPL_A0 out2 -> AND0 in1
         SPL_B0 out1 -> XOR0 in2     SPL_B0 out2 -> AND0 in2
         XOR0 out -> LED S0
         AND0 out -> (carry, leave loose for now)
  TEST:  A0=1 B0=0 -> S0 lit.  A0=1 B0=1 -> S0 DARK (and carry live).
         If S0 stays lit with both on, you wired an OR gate by mistake.

STEP 2 - Bit 1 (first full adder), using 03-logic-cookbook SUB-CIRCUIT 3.
  Its Cin comes from AND0's output via SPL_C1.
  TEST:  A=1,B=1 (i.e. A0=1,B0=1, rest off) should read 0 0 0 1 0 = 2.

STEP 3 - Bits 2 and 3. Identical to bit 1. Copy the wiring exactly.

STEP 4 - Final carry from bit 3's OR gate -> LED S4.
  TEST:  all 8 switches on = 15 + 15 = 30 = 1 1 1 1 0. S0 must be DARK.

--------------------------------------------------------------------------------
POWER - THE PART THAT WILL BITE YOU
--------------------------------------------------------------------------------
Count splitter depth on the worst path. Bit 3's sum travels:
  GEN -> SW -> SPL_A3 (depth 1) -> XOR1 -> SPL_X3 (depth 2) -> XOR2 -> LED
That is fine. But the CARRY CHAIN accumulates across stages:
  bit0 AND -> SPL_C1 (1) -> bit1 AND2 -> OR -> SPL_C2 (2) -> bit2 AND2 -> OR
  -> SPL_C3 (3) -> bit3 -> out
Combined with the input splitter, the deepest path sits around 4-5 splits.

  From ONE Steam Generator (60):  60 -> 30 -> 15 -> 7.5 -> 3.75 -> 1.87
  Still above 1 unit, so it should work - but it is uncomfortably close, and
  the exact gate threshold is not documented on the wiki. VERIFY IN GAME.

RECOMMENDED (and why the BOM says 2 generators):
  - Generator 1 feeds the A0-A3 switch bank.
  - Generator 2 feeds the B0-B3 switch bank.
  This halves the fan-out on each generator immediately and buys you a full
  splitter level of headroom.

IF A HIGH BIT WON'T LIGHT:
  1. Set the splitters on the carry path to 90/10 with 90% going to the carry.
  2. Or insert a COMBINER on the starved line fed by a third generator.
  3. Or just add a generator per row. Coal Generators are 40 iron + 4 electrite,
     which is cheap compared to debugging a brownout.

--------------------------------------------------------------------------------
READING THE OUTPUT
--------------------------------------------------------------------------------
  [S4][S3][S2][S1][S0]  =  16*S4 + 8*S3 + 4*S2 + 2*S1 + 1*S0

  Example: 7 + 9 = 16
  Set A = 0111 (A2,A1,A0 on), B = 1001 (B3, B0 on)
  Expect: S4 lit, S3-S0 all dark.

--------------------------------------------------------------------------------
SCALING AND LIMITS
--------------------------------------------------------------------------------
  Each extra bit costs 9 more blocks (2 XOR, 2 AND, 1 OR, 4 SPL) plus 2 switches
  and 1 LED, and adds one more splitter of depth to the carry chain.
  8-bit version: 89 logic blocks, 16 switches, 9 LEDs, and you will definitely
  need one generator per 2 bits. Doable but it is a genuine construction project.

  This machine ONLY ADDS. It cannot subtract, multiply, compare, or remember.
  See 02-power-rules.txt RULE 6 and 03's "what you cannot cook" for why.
